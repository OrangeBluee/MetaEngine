# Data sources and provenance

- [HMDB](https://hmdb.ca/downloads): obtain XML exports from the official provider under the applicable terms. Reference exports are supplied locally and excluded from this repository. Saliva-specific and full HMDB exports may contain different records; compare accession sets to establish their overlap.
- MS-DIAL: annotation workbooks are imported from local files. Study data and third-party spectral libraries are excluded from this repository.
- Local curated knowledge base: records of saliva occurrence, periodontal association, or vaping association require source citations and curation dates. Template entries illustrate the file format and require independent curation before analysis.

Record the database name, version, download date, file hash, mass tolerance, ion mode, and adduct list with each analysis.
